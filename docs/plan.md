# 구현 계획

## 1. 기존 디자인 이식

- 고정 헤더와 드롭다운 메뉴
- 프로필 및 카테고리 사이드바
- 홈과 카테고리 글 카드
- 게시글 본문과 오른쪽 고정 목차
- 전자부품 배경 장식
- 라이트/다크 모드
- 데스크톱 및 모바일 반응형 레이아웃

## 2. 티스토리 기능 연결

- 홈, 카테고리, 검색 글 목록
- 게시글 본문, 태그, 댓글
- 이전 글과 다음 글
- 같은 카테고리 관련 글
- 오늘, 어제, 전체 방문자 수

## 3. 본문 편의 기능

- 읽기 진행률
- 본문 목차 자동 생성 및 현재 항목 강조
- 코드 복사 버튼
- 표와 코드 블록 가로 스크롤
- 본문 이미지 라이트박스
- KaTeX 수식 표시

## 4. 접근성

- 본문 바로가기
- 의미 있는 HTML 구조
- 키보드 메뉴 및 라이트박스 조작
- 명확한 포커스 표시
- 충분한 색상 대비와 터치 영역
- 모션 감소 환경설정 지원
- 장식 이미지의 스크린리더 제외

## 5. 검수

- 홈, 카테고리, 검색, 게시글, 댓글 화면 확인
- 라이트/다크 모드 확인
- 데스크톱, 태블릿, 모바일 확인
- 키보드만으로 주요 기능 조작 확인
- 실제 티스토리 테스트 블로그 적용 후 최종 조정
