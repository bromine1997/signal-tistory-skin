# Signal

기술 블로그를 위해 만든 회로도풍 티스토리 커스텀 스킨입니다.

> 현재 버전: `0.3.0`

## 목표

- 기존 GitHub Pages 블로그의 시각 디자인과 반응형 레이아웃 재현
- 티스토리 글, 카테고리, 검색, 댓글 치환자 연동
- 라이트/다크 모드, 글 전용 목차, 코드 복사 기능 제공
- 이미지 클릭 확대, 같은 카테고리 관련 글, 방문자 수 카드 제공
- 키보드 탐색, 포커스 표시, 명암비 등 접근성 개선

콘텐츠 이전은 이 저장소의 범위에 포함하지 않습니다.

## 주요 기능

- 반응형 레이아웃: 검색·카테고리·방문자 / 본문 / 글 전용 목차
- 시스템 설정을 따르는 라이트·다크 모드
- 오늘·어제·전체 방문자 수 카드
- 목록 카드 전체 클릭과 댓글 수 표시
- 본문 제목으로 자동 생성되는 고정 목차와 모바일 목차 서랍
- 글·본문 섹션 링크 복사
- 이전·다음 탐색과 개수 표시를 지원하는 이미지 확대 보기
- 언어 표시·복사·긴 코드 접기를 지원하는 코드 블록
- 같은 카테고리의 관련 글
- 댓글, 이전·다음 글
- 소유자 전용 글쓰기·관리자 메뉴와 글 수정·상태 변경·삭제 도구
- 본문 바로가기, 명확한 포커스, 모션 감소 설정 등 접근성 지원

## 설치

1. 이 저장소를 내려받습니다.
2. 티스토리 관리 화면에서 **꾸미기 → 스킨 변경 → 스킨 등록**으로 이동합니다.
3. `skin.html`, `style.css`, `index.xml`, `LICENSE`를 등록합니다.
4. `images/script.js`는 `images` 폴더의 파일로 등록합니다.
5. 등록한 스킨을 보관함에서 선택하고 적용합니다.
실제 블로그에 적용하기 전 테스트 블로그에서 먼저 확인하는 것을 권장합니다. `index.xml`을 다시 업로드하면 기존 스킨 옵션이 초기화될 수 있습니다.

티스토리 기본 **카테고리 글 더 보기** 영역은 Signal의 관련 글과 중복되지 않도록 자동으로 숨깁니다.

등록용 ZIP 파일은 다음 명령으로 만들 수 있습니다.

```bash
./scripts/package.sh
```

결과물은 `dist/Signal-v<버전>.zip`에 생성됩니다.

## 구조

```text
.
├── skin.html       # 티스토리 메인 스킨 템플릿
├── style.css       # 스킨 스타일
├── index.xml       # 스킨 정보와 사용자 설정
├── images/
│   └── script.js   # 인터랙션과 접근성 기능
└── docs/
    └── plan.md     # 구현 범위와 단계
```

## 0.3.0 변경 사항

- 검색을 상단바에서 사이드바로 이동
- 글 목록 카드 전체 클릭과 댓글 수 표시
- 모바일 목차, 글·섹션 링크 복사 기능 추가
- 코드 언어 표시와 긴 코드 접기 기능 추가
- 이미지 확대 보기의 이전·다음 탐색과 개수 표시 추가
- 소유자에게만 보이는 글쓰기·관리자·글 관리 도구 추가

## 0.2.2 변경 사항

- 목록·카테고리 화면의 중복 글 출력 제거
- 외부 프로필 링크와 고정 기술 스택 제거
- 글이 아닌 화면의 빈 목차 제거
- 댓글 치환자와 티스토리 코드 블록 호환성 개선
- 관련 글 중복 방지, 이미지 확대와 반응형 배경 장식 개선
