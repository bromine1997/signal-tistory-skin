# Signal

기술 블로그를 위해 만든 회로도풍 티스토리 커스텀 스킨입니다.

> 현재 버전: `0.2.1` — 실제 티스토리 적용 전 1차 구현본

## 목표

- 기존 GitHub Pages 블로그의 시각 디자인과 반응형 레이아웃 재현
- 티스토리 글, 카테고리, 검색, 댓글 치환자 연동
- 라이트/다크 모드, 읽기 진행률, 고정 목차, 코드 복사 기능 제공
- 이미지 클릭 확대, 같은 카테고리 관련 글, 방문자 수 카드 제공
- 키보드 탐색, 포커스 표시, 명암비 등 접근성 개선

콘텐츠 이전은 이 저장소의 범위에 포함하지 않습니다.

## 주요 기능

- 반응형 3열 레이아웃: 프로필·카테고리 / 본문 / 글 목차
- 시스템 설정을 따르는 라이트·다크 모드
- 오늘·어제·전체 방문자 수 카드
- 본문 제목으로 자동 생성되는 고정 목차
- 읽기 진행률과 예상 읽기 시간
- 본문 이미지 키보드 접근 가능한 확대 보기
- 코드 복사 버튼과 표 가로 스크롤
- 같은 카테고리의 관련 글
- 검색, 댓글, 이전·다음 글
- 본문 바로가기, 명확한 포커스, 모션 감소 설정 등 접근성 지원

## 설치

1. 이 저장소를 내려받습니다.
2. 티스토리 관리 화면에서 **꾸미기 → 스킨 변경 → 스킨 등록**으로 이동합니다.
3. `skin.html`, `style.css`, `index.xml`, `LICENSE`를 등록합니다.
4. `images/script.js`는 `images` 폴더의 파일로 등록합니다.
5. 등록한 스킨을 보관함에서 선택하고 적용합니다.
6. 스킨 편집의 설정 화면에서 선택형 GitHub 및 포트폴리오 주소를 입력합니다. 비워두면 관련 메뉴와 아이콘은 표시되지 않습니다.

프로필 이름, 이미지, 소개는 스킨에 저장하지 않고 설치한 티스토리 블로그의 필명, 대표 이미지, 설명을 사용합니다.

실제 블로그에 적용하기 전 테스트 블로그에서 먼저 확인하는 것을 권장합니다. `index.xml`을 다시 업로드하면 기존 스킨 옵션이 초기화될 수 있습니다.

등록용 ZIP 파일은 다음 명령으로 만들 수 있습니다.

```bash
./scripts/package.sh
```

결과물은 `dist/Signal-v<버전>.zip`에 생성됩니다.

## 구조

```text
.
├── skin.html       # 티스토리 메인 스킨 템플릿
├── style.css       # 스킨 스타일
├── index.xml       # 스킨 정보와 사용자 설정
├── images/
│   └── script.js   # 인터랙션과 접근성 기능
└── docs/
    └── plan.md     # 구현 범위와 단계
```

## 개발 상태

핵심 화면과 기능을 구현한 1차 버전입니다. 실제 티스토리 렌더링 결과를 기준으로 치환자 출력 구조와 모바일 화면을 추가 조정할 예정입니다.
